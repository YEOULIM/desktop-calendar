      알림

        바탕화면 캘린더의 알림 팝업은 화면 오른쪽 아래에 떠요. 다른 창이 바탕화면을 덮고 있으면 팝업은 가려지고 소리만 들려요.

        설정

        위쪽 ↻ 버튼으로 새로고침
        시 ~ 시

        바탕화면에 띄울 때 캘린더가 놓일 위치와 크기예요. 이 설정은 기기마다 따로 저장되니 폰에는 영향이 없어요.

        현재 화면 크기:
        캘린더 오른쪽 위 ─ 버튼을 누르면 작은 카드로 접히고, 카드를 누르면 다시 펼쳐져요.

        중국 일정은 매년 11월쯤 국무원 발표 후 자동으로 받아와요(인터넷 연결 필요). 2026년은 파일에 내장돼 있어요. 한국 임시공휴일처럼 새로 생긴 휴일은 아래에 직접 추가하세요.

          1. console.firebase.google.com 에서 프로젝트를 만들어요.
          2. Build → Authentication → 로그인 방법에서 이메일/비밀번호를 사용 설정해요.
          3. Build → Firestore Database → 데이터베이스 만들기 (위치: asia-northeast3 서울).
          4. Firestore → 규칙 탭에 아래 규칙을 붙여넣고 게시해요.
          5. 프로젝트 설정 → 내 앱 → 웹 앱(</>) 추가 → 나오는 firebaseConfig 내용을 아래 칸에 통째로 붙여넣어요.
          rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /users/{uid}/{doc=**} {
      allow read, write: if request.auth != null
                         && request.auth.uid == uid;
    }
  }
}

          PC와 폰에서 각각 한 번씩 같은 설정을 붙여넣고 같은 계정으로 로그인하면 돼요.

          할 일·반복 작업·알림·직접 추가한 휴일을 파일로 내보내거나 불러와요. 불러오면 지금 내용이 파일 내용으로 바뀌어요.

          바탕화면에서는 파일 저장·열기가 막혀 있어서, 아래처럼 복사해서 보관하고 붙여넣어서 불러와요. 복사한 내용은 메모장·카톡 나에게 보내기 등에 붙여넣어 두면 돼요.

          자동 기록 (이 기기)

          동기화로 내용이 바뀌기 전, 백업을 불러오기 전, 그리고 하루 한 번 이 기기에 자동으로 저장돼요. 원하는 시점의 되돌리기를 두 번 누르면 그때 내용으로 돌아가요.
